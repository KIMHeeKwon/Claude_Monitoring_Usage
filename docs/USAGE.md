# Claude Usage 사용 안내

내 Claude 구독 한도와 이 PC의 CPU·메모리·GPU를 작은 창 하나에 띄워 두는 프로그램입니다.
서버가 없고 각자 자기 계정으로 씁니다.

---

## 1. 설치

받은 설치 파일(`Claude Usage_0.0.1_x64-setup.exe`)을 실행합니다. 관리자 권한은 필요 없습니다.

**"Windows의 PC 보호" 경고가 뜹니다.** 서명을 하지 않은 프로그램이라 그렇습니다.
**추가 정보**를 누른 뒤 **실행**을 누르십시오.

> 이미 쓰고 계신 분이 새 버전을 설치할 때는, **먼저 트레이 아이콘을 우클릭해 "종료"**를 누르십시오.
> 창의 X 버튼은 숨기기일 뿐 프로그램은 살아 있습니다. 켜 둔 채로 설치하면 설정이 되돌아갈 수 있습니다.

---

## 2. 처음 켰을 때

설치하면 창이 화면 왼쪽 위에 뜹니다. **CPU·메모리·GPU는 바로 보이고, Claude 한도는 연결이 필요합니다.**

창이나 트레이 아이콘을 **우클릭**하면 메뉴가 열립니다. 아래 두 항목을 확인하십시오.

| 항목 | 해야 할 일 |
|---|---|
| **실시간 조회** | **켜져 있어야 합니다.** 기본값이 켜짐이지만 꺼져 있으면 눌러서 켜십시오. 3분 안에 값이 들어옵니다 |
| **Claude 한도 연결** | 실시간 조회를 쓰면 없어도 되지만, 켜 두면 Claude Code 사용 중에 더 자주 갱신됩니다 |

값이 들어오면 5시간 창과 주간 사용률이 숫자로 나타납니다.

---

## 3. 화면 읽는 법

| 표시 | 뜻 |
|---|---|
| **5H LIMIT** | 5시간 창 사용률. 가장 먼저 차는 한도입니다 |
| **주간 / WEEK** | 이번 주 전체 사용률 |
| **Fable, Opus 같은 모델 이름** | 그 모델의 주간 사용률. **실시간 조회를 켰을 때만** 나옵니다 |
| **CPU · MEM · GPU** | 이 PC의 사용률. GPU는 작업 관리자와 같은 방식으로 잽니다 |
| 오른쪽 위 작은 글씨 | 값을 어디서 가져왔는지 (`OAUTH`는 실시간 조회, `STATUSLINE`은 Claude Code) |

### 색이 바뀝니다

| 상태 | 색 | 조건 |
|---|---|---|
| 정상 | 파랑 | 5시간 창 75% 미만 |
| 주의 | 주황 | 75% 이상. 숫자와 창 테두리가 바뀝니다 |
| 위험 | 빨강 | 90% 이상. 숫자가 깜빡입니다 (메뉴에서 끌 수 있습니다) |
| 끊김 | 회색 | 값이 5분 넘게 갱신되지 않음. 테두리가 점선이 되고 "끊김 N분 전 값"이 뜹니다 |

**끊김일 때도 CPU·메모리·GPU는 원래 색으로 계속 움직입니다.** 한도만 옛 값이라는 뜻입니다.

## 4. 창 다루기

| 하고 싶은 것 | 방법 |
|---|---|
| 창 옮기기 | 왼쪽 위(라벨이 있는 부분)를 잡고 끕니다. 위치는 다음에 켤 때도 유지됩니다 |
| 창 숨기기 | 창의 X, 또는 우클릭 메뉴의 "창 숨기기" |
| 다시 보이기 | 트레이 아이콘을 좌클릭 |
| **완전히 끄기** | 트레이 아이콘 우클릭 → **종료** |

---

## 5. 우클릭 메뉴

| 항목 | 설명 |
|---|---|
| **레이아웃** | 일곱 가지 중에서 고릅니다. 고르면 창 크기가 그 모양에 맞게 바뀝니다 |
| **크기** | 100 · 125 · 150 · 175%. 창과 글씨가 함께 커집니다. 기본은 125% |
| **테마** | 다크 · 라이트 · 시스템 따라감 |
| **Claude 한도 연결** | Claude Code(터미널)를 쓰는 동안 값을 받아 옵니다 |
| **실시간 조회** | 3분마다 직접 조회합니다. 모델별 한도는 이것을 켜야 보입니다 |
| **위험 시 숫자 깜빡임** | 90%를 넘었을 때 깜빡이게 할지 |
| **예시 값 표시** | 가짜 값으로 화면을 확인할 때 씁니다. 평소에는 꺼 두십시오 |
| **종료** | 프로그램을 끝냅니다 |

### 레이아웃 일곱 가지

| 이름 | 특징 |
|---|---|
| 2a 3칸 분할 | 계기 + 한도 막대 + 시스템 세 칸. 기본값 |
| 2b 계기 3연 | 5시간·주간·모델을 같은 계기로 나란히 비교 |
| 2c 초슬림 리본 | 높이 62px. 화면을 가장 적게 차지합니다 |
| 2d 계기 + 긴 히스토리 | 최근 40초 CPU·GPU 흐름을 크게 봅니다 |
| 2e 눈금 막대 계기판 | 다섯 값을 같은 자에 세워 절대값 비교 |
| 2f 도트 매트릭스 | 한도를 셀 수 있는 칸으로 표시 |
| 2g 계기 + 링 3연 | 시스템 지표도 링으로 |

**모델별 한도(Fable 등)는 2a·2b·2d·2f에만 자리가 있습니다.** 다른 레이아웃에서는 보이지 않습니다.

## 6. 실시간 조회에 대해 (읽어 주십시오)

실시간 조회는 Claude Code가 저장해 둔 로그인 정보를 읽어 사용량을 직접 물어보는 방식입니다.
**Anthropic이 공식으로 안내한 방법이 아닙니다.** 약관은 구독 계정의 로그인 정보를 다른 프로그램에서
쓰는 것을 금지하고 있으며, 사용량 조회 도구들이 현재 문제없이 쓰이고 있으나 앞으로도 그러리라는
보장은 없습니다.

- 부담스러우시면 우클릭 메뉴에서 **실시간 조회를 끄십시오.** 대신 Claude Code(터미널)를 쓰는 동안에만
  값이 갱신되고, 모델별 한도는 보이지 않습니다.
- 이 프로그램은 로그인 정보를 **읽기만** 합니다. 저장하거나 다른 곳에 보내지 않습니다.
- Anthropic 외에는 어디에도 접속하지 않습니다.

## 7. 잘 안 될 때

| 증상 | 해결 |
|---|---|
| 한도 값이 `–`로만 나온다 | 우클릭 메뉴에서 실시간 조회를 켜십시오. 3분 안에 들어옵니다 |
| Fable이나 Opus가 안 보인다 | ① 실시간 조회가 켜져 있는지 ② 레이아웃에 자리가 있는지(위 표 참고) ③ 그 모델을 이번 주에 썼는지 |
| "Claude Code 세션을 한 번 여세요" | 터미널에서 `claude`를 실행하고 대화를 한 번 주고받으십시오. 실행만으로는 값이 안 나옵니다 |
| "로그인 갱신 필요" | 터미널에서 `claude`를 한 번 실행하십시오. 로그인이 새로 고쳐집니다 |
| GPU 행이 안 보인다 | 이 환경에서 GPU 값을 읽지 못한다는 뜻입니다. 나머지는 정상 동작합니다 |
| GPU 옆에 용량이 없다 | NVIDIA 그래픽카드에서만 메모리 용량이 나옵니다 |
| 값이 실제와 다르다 | 회색으로 보인다면 갱신이 끊긴 것입니다. "끊김 N분 전 값"이 함께 뜹니다 |
| 창이 사라졌다 | 트레이 아이콘을 좌클릭하십시오 |
| 앱이 안 꺼진다 | 창의 X는 숨기기입니다. 트레이 우클릭 → 종료 |

---

## 8. 아직 안 되는 것

- **macOS 버전**: 준비 중입니다. 지금은 Windows만 됩니다.
- **Claude 웹·데스크톱 앱만 쓰는 경우**: 실시간 조회를 켜면 한도가 보입니다. 끄면 보이지 않습니다.
- **NVIDIA가 아닌 그래픽카드**: 사용률은 나오지만 메모리 용량은 표시되지 않습니다.
